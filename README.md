Application Python de gestion des tâches
1. Présentation du projet
Cette application Python permet de gérer des tâches quotidiennes dans une interface console. Chaque tâche possède un numéro et un titre.
2. Fonctionnalités
•	Ajouter une tâche : saisir un titre et l’ajouter à la liste. Une saisie vide est refusée.
•	Afficher les tâches : afficher toutes les tâches avec leurs numéros.
•	Rechercher une tâche : rechercher les tâches à partir d’un mot-clé contenu dans leur titre.
•	Quitter : fermer le programme.
Toute option invalide affiche un message d’erreur.
3. Notions Python utilisées
•	Variables
•	Listes et dictionnaires
•	Conditions
•	Boucle while
•	Boucle for
•	Fonctions
•	Saisie avec input()
4. Exécution du programme
1.	Ouvrir le dossier du projet dans Visual Studio Code.
2.	Ouvrir le fichier main.py.
3.	Cliquer sur Run Python File.
4.	Utiliser le menu dans le terminal.
5. Fichiers du projet
•	main.py : code source de l’application.
•	README.md : documentation du projet.
